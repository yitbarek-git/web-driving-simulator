# Open Road Simulator

A browser-based driving game set on a winding 3 km mountain highway. Pick a
paint color, switch camera views, and take a lap at your own pace.

## Drive

| Key | Action |
| --- | --- |
| W or Up Arrow | Accelerate |
| S or Down Arrow | Brake or reverse |
| A/D or Left/Right Arrow | Steer |
| Space | Handbrake |
| C | Change camera |
| R | Reset the car |
| Esc | Pause |
| H | Show or hide driving hints |

## Run locally

You'll need [Node.js](https://nodejs.org/). From the project folder, install
the dependencies and start the development server:

```bash
npm install
npm run dev
```

Open the local address printed in the terminal.
